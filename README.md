# PeoplePay360 HR & Payroll

Integrated HR, payroll and employee self-service workspaces with live dashboard KPIs.

See [the implementation and operating guide](docs/IMPLEMENTATION.md) for roles, complete workflows, API routes, configuration, metric definitions, tests and demo instructions.

Run `npm run dev` from this directory. Sign in at `http://localhost:3000/login`; your account role selects the dashboard.
